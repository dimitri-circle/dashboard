Reactive Dot Ribbon

One animated layer. Two clean uses.

Use the element as a fixed page background or as an inline interactive ribbon. Background mode stays behind content and never captures clicks.

Current tutorial

Install once, choose the mode you need.

Load script.js, include dots-pattern.webp, then place <reactive-dot-ribbon> where the motion belongs.

Page background

Put this before the page content. It is fixed, non-interactive, and hidden from assistive technology. 

<reactive-dot-ribbon
  background
  aria-hidden="true"
  source="./dots-pattern.webp"
></reactive-dot-ribbon>

Inline ribbon

Use this when the ribbon is visible content. Keep the label and optional hint aligned with the interaction. 

<reactive-dot-ribbon
  aria-label="Interactive halftone ribbon"
  hint="Move pointer through dots"
  source="./dots-pattern.webp"
  style="--dot-ribbon-aspect: 2048 / 1094;"
></reactive-dot-ribbon>
